# Assets

Static assets. Self-contained by the same rule the dashboard follows: no
external font, script, or image reference, so every file works offline and
carries no supply-chain surface.

| File | What it shows |
| --- | --- |
| `pipeline.svg` | The full data path — capture, the token branch, the read side, and the three things that constrain what A01 may claim |

`pipeline.svg` paints its own background rather than inheriting the page it is
embedded in, so it stays readable in a light or dark viewer.
